About Me

Halo. Saya Sony Habibi, siswa kelas XI Pengembangan Perangkat Lunak & Gim (PPLG) di SMK TI Dwiguna.

Saya tertarik dengan pengembangan website dan teknologi. Biasanya, saya mulai dari memikirkan ide untuk sebuah project, lalu menggunakan AI sebagai alat bantu untuk mengembangkan ide tersebut menjadi kode. Dari proses itu, saya mencoba memahami cara kerja project, melihat hasilnya, dan memperbaiki bagian yang belum sesuai.

Saat ini, saya sedang belajar web development menggunakan PHP dan Laravel, mengenal Git & GitHub, serta mencoba pengembangan gim dan teknologi lainnya. Saya masih dalam tahap belajar dan ingin terus menambah pengalaman melalui project pribadi maupun kegiatan sekolah. Saya juga sedang mempersiapkan diri untuk mengikuti proses seleksi dan wawancara PKL.
